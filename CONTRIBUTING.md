# Contributing

Thank you for helping curate Awesome Arabic AI. Follow the rules below to keep the list consistent and useful.

## Submission Rules

1. Entries must explicitly serve the Arabic language or regional developer workflows. General tools without Arabic support or Arabic documentation do not qualify.
2. Keep descriptions to one factual sentence ending with a period. No marketing adjectives or promotional phrasing.
3. Maintain alphabetical sorting within sections. Insert each new entry in the correct alphabetical position by tool name.
4. Include active links only. Do not submit commercial landing pages without direct developer utility. Link to the official repository, documentation, or tool page.

## Entry Format

Use this exact markdown format for every entry:

```markdown
- [Name](URL) - Description.
```

Example:

```markdown
- [Tool Name](https://example.com) - Short description ending with a period.
```

Checklist for each entry:

- Name matches the official project name.
- URL uses HTTPS and points to the official source.
- Description is one sentence, factual, and ends with a period.
- Entry is placed in alphabetical order.

## How to Submit Changes via Pull Request

1. Fork the repository and create a branch for your change.
2. Add or update entries in `README.md` and mirror the change in `README.ar.md` when applicable.
3. Verify links are live and descriptions follow the format above.
4. Run the lint workflow locally if possible (see `.github/workflows/lint.yml`).
5. Open a Pull Request with a clear title and complete the Pull Request checklist.
6. Wait for review. Address requested changes by pushing new commits to the same branch.
